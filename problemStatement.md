Backend Requirements

The focus will be on how data is consumed, processed, and served to the front-end.


1. Data Handling & Processing · Develop a strategic plan to consume and process data from the provided API: https://dev-task.elancoapps.com/.

· Consider how to handle large datasets, duplicates, and incomplete data.

2. API Endpoints

· Create an endpoint to accept new sighting reports submitted from the front-end form.

· Allow frontend users to search and filter sightings by time range and location.

· Provide endpoints to deliver aggregate insights, such as the number of sightings per region and trends over time (weekly or monthly).

3. Error Handling

· Implement robust error handling for external API failures, data inconsistencies, and invalid user submissions.












Frontend Requirements

Your submission must contain a minimum of 2 requirements from each of the different areas below.

1. Interactive Map Visualization

· A dynamic map interface displaying tick sightings across the UK.

· Map markers with visual indicators (e.g., for severity, recent activity, or species).

· Filter controls to refine the data shown on the map (e.g., by date range, species type).

2. Sighting Information

· A modal or sidebar panel with detailed sighting information when a user clicks on a map marker.

· A timeline view showing the progression of tick activity in a selected area.

· Quick action buttons like "Get Directions" or "Share".

3. Educational Content

· A guide to help users identify different tick species.

· A section with tips for preventing tick bites.

· A chart to illustrate seasonal tick activity in a specific location.

4. Report a Sighting

· A user-friendly form to report a new tick sighting (including date, location, species, etc.).

· Form validation with clear error, warning, and success messages.

· The ability for users to upload images with their sighting report.
